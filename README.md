# Sinister Secrets

Python/Ursina first-person horror prototype.

## Controls
- W A S D - Move
- Mouse - Look
- Shift - Sprint
- E - Interact
- F - Flashlight
- R - Restart after death/win
- Esc - Quit

## Prototype 0.1
- First-person movement
- Flashlight + battery
- Key pickup
- Locked exit door
- Ghost patrol/investigate/search/chase AI
- Ghost vision + hearing
- A* waypoint navigation
- Win / lose states

Run with:

```powershell
python main.py
```
